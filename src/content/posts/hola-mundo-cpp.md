El Hola Mundo es el programa más básico que se puede escribir en cualquier lenguaje de programación.

Estructura básica de un programa Hola Mundo:

```cpp
#include <iostream>

int main() {
    std::cout << "Hola, mundo!" << std::endl;
    return 0;
}
```
